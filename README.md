# 🐈 Gato Nuevo — Motor TMH2 (9-Bit)

Bienvenido al compartimiento oficial de **Gato Nuevo**, un sistema de procesamiento lógico visual diseñado para correr sobre la arquitectura de 9 bits de **Gato OS** y el motor **TMHS 2 CMH**.

Este repositorio contiene la configuración limpia del patio de juegos en línea, protegiendo el código del interior para el usuario final y permitiendo la ejecución de carreras a alta velocidad.

---

## 🚀 Especificaciones del Hardware Virtual

El motor procesa la información en segundo plano actuando como un demonio (*daemon*) optimizado bajo los siguientes parámetros de control:

* **Arquitectura de CPU:** 9 bits estrictos.
* **Frecuencia del Reloj:** 2,000 vueltas lógicas por ciclo (2000 Hz).
* **Renderizado Multimedia:** Integración directa de archivos gráficos (.gif) alojados en la web.
* **Economía del Juego:** Sistema de recompensas basado en **Cat Coins**.

---

## 🎛️ Diccionario de Símbolos (`.tmh`)

El archivo nativo `.tmh` lee y procesa una cadena de símbolos específicos a través de los cables del tablero:

| Símbolo | Componente | Función Principal |
| :---: | :--- | :--- |
| `>` | **Avance** | Genera un impulso de aceleración lineal para el Gato Nuevo. |
| `~` | **Inversor** | Modificador lógico de objetivo único (Falso Friends Perfecto). |
| `?` | **Condición** | Verifica colisiones y altera las físicas mediante el Efecto Doppler. |

---

## 🖥️ Interfaz del Patio de Juegos (Modo Usuario)

Para evitar entrar en bucles de demostración y mantener la pantalla nítida, la barra de control maestro de la interfaz web incluye:

1. **Salvar / Cargar:** Guarda el mapa de bloques actual en archivos de configuración ligera.
2. **Detener / Paso:** Detiene el flujo eléctrico virtual o ejecuta el código ciclo por ciclo para detectar fallas.
3. **En Vivo (Live Run):** Activa las 2,000 vueltas lógicas en tiempo real.
4. **Agrandar:** Maximiza el lienzo ocultando las herramientas de desarrollo para una experiencia limpia a pantalla completa.
